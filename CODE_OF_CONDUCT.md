# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full and
without modification.

The canonical text and translations are published at:

* English: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
* Markdown source: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>
* Translations: <https://www.contributor-covenant.org/translations/>

## What this means in practice

* Be respectful. Disagree with ideas, not people.
* Assume good intent; ask for clarification before escalating.
* No personal attacks, no demographic slurs, no off-topic baiting.
* Keep discussion focused on the project.

## Scope

This applies anywhere this project is represented — issues, pull requests,
commit messages, discussions, and any other public or private channel where
participants are acting on behalf of the project.

## Reporting

Reports go to **althrussell@gmail.com** (Al Thrussell, project maintainer).

Please include:

* Where it happened (issue/PR/discussion link, channel)
* Who was involved
* What was said or done (links / screenshots ideal)
* Any other context that's useful

Reports are confidential. Acknowledgement within 72 hours; resolution as
fast as practical after that.

## Enforcement

The maintainer follows the Contributor Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
to decide on consequences — typically: private warning → public warning →
temporary ban → permanent ban. The maintainer's decision is final for this
project.
